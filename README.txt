NovaHA TalentHub - Simple demo

How to run (requires Node.js >= 14):

1. Open terminal in project folder.
2. Install dependencies:
   npm install

3. Start server:
   npm start

4. Open browser:
   http://localhost:3000  -> Student form
   http://localhost:3000/admin -> Admin list

Notes:
- Uploaded CVs are stored in the uploads/ folder.
- Student records are stored in data/students.json (simple JSON storage for demo).
- This is a minimal demo to run locally in VSCode. For production, replace JSON storage with a proper DB.
